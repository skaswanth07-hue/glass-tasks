# Glas Tasks

A clean, simple to-do list app for keeping track of what you need to get done.

## Features

- Add, edit, and delete tasks
- Mark tasks as complete
- Set due dates and priorities
- Filter by All / Active / Completed
- Tasks saved automatically

## Getting Started

### Prerequisites

- Python 3.10+

### Installation

1. Clone the repository
```bash
   git clone https://github.com/your-username/glas-tasks.git
   cd To do.py
```
3. Run the app
   Run in python

## Usage

1. Type a task in the input box and press Enter (or tap Add).
2. Tap a task to mark it done.
3. Use the filters to switch between active and completed tasks.
